# Power Design Toolkit V9.2.1 发布说明

发布日期：2026-09-15

V9.2.1 是一个**文档与可用性**版本，功能面与 V9.2.0 相同，但补上了此前最大的短板：
**程序内没有任何帮助**，以及**没有任何实现原理说明**。

对工程设计工具来说，文档和帮助不是附属品：只有知道一个数字是怎么算出来的、
它隐含了哪些假设，才能判断它能不能用来支持一个设计结论。本版把这件事补齐。

## 1. 应用内帮助系统（新增）

四个工作区（LLC / PFC / Control Tools / FRA Loop Designer）工具栏各新增 **帮助** 按钮，
**F1** 随时打开；功能选择页也新增「使用说明 / 帮助 (F1)」。

帮助内容随程序分发，不依赖浏览器或 PDF，界面为「章节列表 + 正文浏览器」，
每个工作区包含：

| 章节 | 内容 |
| --- | --- |
| 快速上手 | 该工作区的操作顺序，以及每个页面/结果页在做什么 |
| 页面与参数说明 | 控制器类型与参数对照、采样链、离散化、导出含义 |
| **实现说明** | 算法与系数约定到底是怎么算的（见第 2 节） |
| 模型边界与已知限制 | 声明的假设，以及不能用来声称的结论 |
| 快捷键与操作 | F1 / F4 / F8 / F9 / Ctrl+R 等 |
| 联系方式与支持 | 邮箱、微信、公众号二维码，以及发邮件该附什么 |
| 打开文档 | 本地 Markdown 存在时直接打开，打包版自动回退到 GitHub 同名文档 |

快捷键：F1（各工作区）、F4 设计参数（LLC）、F8 运行日志（LLC）、F9 专注模式（LLC）、
Ctrl+R 运行当前页面（LLC）。

## 2. 实现说明（新增，本版重点）

帮助中新增「实现说明」章节，写的是**数字是怎么算出来的**，不只是功能清单：

**LLC**

* FHA：只取桥输出基波（全桥 4/π·Vbus、半桥 2/π·Vbus），副边折算为等效交流负载
  Rac（含 SR 压降折算），谐振腔按 Lr–Cr–Lm 分压求增益，工作点用一维标量求根。
* HB：不是各次谐波分别套 FHA 相加，而是把全波整流钳位与选定奇次谐波电流**自洽联立**
  （`Ir_h = (Vbridge_h − Vprimary_h)/Zseries`、`Im_h = Vprimary_h/Zm`），
  换向时刻由重构负载电流极性产生；默认谐波序列 H1 → H1/H3/H5 → H1/H3/H5/H7。
* TD：分段线性周期稳态求解器，求周期不动点，理想开关。
* 数字环：**混合域**求值（连续块 s=jω，数字块 z=exp(jωTs)），级联顺序
  模拟滤波 → ADC 多 SOC 递归平均 → 控制器 → PCMD → 分段 FM LUT → PWM/ZOH → Gvf；
  延时由 `application_delay` 减 ADC 有效采样偏移得到"采样到动作"延时，
  拆成整数采样 + Thiran 分数延时，并给出 MIN/NOMINAL/MAX 三种延时包络的裕度。

**PFC / Vienna**

* 采样链显式建模 `soc_count`/`soc_spacing`、`computation_delay`、`pwm_update_delay`；
  工程约定：**ADC/SOC 延时归采样块，计算与 PWM 更新延时归固件块，两块不重复计数**
  （历史版本曾双重计数，导致相位多损失、裕度偏悲观）。
* 电流环用 `current_computation_delay_s`，电压环用 `amc_update_delay_s +
  voltage_computation_delay_s`；采样块的多 SOC 平均同时影响所有环路。
* 开关电流重构按**跨 PWM 周期连续积分**；AC 周期求解器推进整条工频周期到 settled。

**Control Tools**

* 系数约定与 a0 归一化；离散化**自己实现**二项式映射：
  Tustin `s = 2Fs(1−q)/(1+q)`、预畸变 `k = ωp/tan(ωp/(2Fs))`、后向欧拉 `s = Fs(1−q)`；
  不用 `scipy.cont2discrete` 的原因写明（理想 PID 非真分会被拒）。
* C99 导出：单文件 header-only、`float32_t`、SOS 级联 + DF2T 递推式
  （`y=b0x+d1; d1=b1x−a1y+d2; d2=b2x−a2y`），系数符号与界面 H(z) 完全一致；
  导出后本机编译并与 Python 参考逐点比对。
* 稳定性判定阈值：`|p|>1+1e-9` UNSTABLE（禁导出）、`|p|≥1−1e-9` MARGINAL
  （积分器/PI 属于此类，仍可导出）、其余 STABLE。

**FRA Loop Designer**

* H(z) 按 z⁻¹ 定义直接代入求值；相位先 unwrap，再按「离最近的奇数倍 180° 分支」
  计算裕度，遍历全部 −180°+360°k 分支，重复穿越与多圈相位都能正确处理。
* 剥离 `G_eq = H_scan/C_old` 后立即代数重建并报告误差；
  明确写出这只是复数除乘自检，**不是** `C_old` 来源证明。
* 有理辨识 = **变量投影法**：先参数化极点（实极点 + 复共轭对），
  分子用线性最小二乘一次解出，外层 `least_squares(soft_l1)` 搜极点/阻尼/延时；
  多项式变量归一化为 `x = s/w_ref`；纯延时在频域显式 `exp(−jωTd)`，
  仅做阶跃/极点计算时转一阶 Padé。明确写：**不是 Vector Fitting**，不是元件辨识。
* 辨识模型 × 控制器：ZOH 采样 + 精确离散控制器闭环，
  并写明 z⁻¹ 升幂与 scipy 正幂降序之间**分子需补尾部零**才能保持采样对齐
  （已用独立 `lfilter` 差分方程验证到 1e-14）。
* Step 授权链顺序：拟合置信度 → 被控对象稳定性 → 环路裕度 → 带宽覆盖 → 闭环稳定性，
  五个 `WITHHELD_*` 状态全部列出条件。
* Auto Design：先由目标 PM 反推所需控制器相位并一维搜索结构参数，
  再一次增益求解使 |L(Fc)|=1，最后在**原始实测点**上评估全频段约束并打分。

## 6. 已知限制（与 V9.2.0 相同，未变化）

1. 实测 Bode100 Complete Loop 文件本身不含固件控制器参数；
   没有真实 `C_old` 时不能产出物理有效的被控对象。
2. `PM`/`GM`/`Ms`/`Mt` 是在「被控对象不含未计入的右半平面极点」假设下成立的
   频域鲁棒性证据，不是与拓扑无关的闭环稳定性证明。
3. 采样 `Ms`/`Mt` 在扫频点之间为低置信度，不能当作数学上界。
4. 有理拟合被约束在稳定半平面，无法辨识真正不稳定的开环被控对象。
5. Auto Design 的自动综合覆盖 PI / PIF / PID / Power 2P2Z / Power 3P3Z；
   其余结构支持手动设计与精确 H(z) 入口。
6. FHA/HB/TD 与所有平均模型都有自己的适用边界，见各工作区帮助的
   「模型边界与已知限制」。
