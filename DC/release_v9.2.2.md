# Power Design Toolkit V9.2.2 发布说明

发布日期：2026-09-15

V9.2.2 为**多语言界面**版本。功能面与 V9.2.1 相同，新增简体中文 / English / 日本語 / 한국어
四种界面语言，并补齐帮助与 README 的语言说明。已有海外用户，因此本版把界面语言作为正式能力。

## 1. 支持的语言与切换方式

| 语言 | 说明 |
| --- | --- |
| 简体中文 | **源语言**。代码中的界面文字即简体中文，词典为空，任何缺失都回退到原文 |
| English | 完整外壳 + 帮助（含实现说明） |
| 日本語 | 外壳 + 帮助导航 + 通用章节，长技术正文按章节补齐 |
| 한국어 | 外壳 + 帮助导航 + 通用章节，长技术正文按章节补齐 |

切换位置：任意工作区工具栏最右侧 **「语言 / Language」**。选择后立即生效，写入设置，
下次启动沿用；也可在功能选择页进入帮助查看说明。

## 2. 翻译策略（重要）

* **界面中原本就是英文的内容不翻译**：`Bode`、`H(z)`、`C99`、`Kp`、`Ti`、`PM`、`GM`、`FRA`、
  `Summary`、`PowerDesignTool`、型号与单位等，在任何语言下都保持原样。
  工程术语的一致性比逐字翻译更有价值。
* **帮助按章节翻译**。尚未提供当前语言正文译文的章节，会在正文上方明确提示
  「此章节暂无当前语言的正文译文，以下显示原文」，而不是静默给出混杂内容。
  章节标题、导航、联系方式、快捷键、通用章节已完成四语言。
* **缺词回退**：词典以源字符串为键，任何未翻译的字符串都原样显示，不会出现空标签或键名。

## 3. 字体随语言切换

共用汉字在中文字体与日韩字体中的字形不同（例如 直 / 骨 / 次），只靠系统回退会让日韩用户
看到中文字形。本版按语言设置字体栈：

| 语言 | Qt 字体栈（取第一个已安装者） |
| --- | --- |
| 简体中文 | Microsoft YaHei UI / Microsoft YaHei / PingFang SC / Noto Sans CJK SC / 思源 / 文泉驿 |
| English | Segoe UI / Helvetica Neue / Noto Sans |
| 日本語 | Meiryo / Yu Gothic UI / Yu Gothic / Hiragino Sans / Noto Sans CJK JP |
| 한국어 | Malgun Gothic / Apple SD Gothic Neo / Noto Sans CJK KR / NanumGothic |

matplotlib 图表的 `font.sans-serif` 同步切换，因此 Bode/波形图上的中文注释、导出 PDF
也随语言一致。

## 4. 实现方式

* `llc_design/i18n/`：`t()` + 四份词典 + 语言注册表 + 字体栈；**不导入 Qt**，
  因此 CLI、报告与代码生成也能复用。
* `llc_design/gui/i18n_ui.py`：窗口构建完成后**自动扫描**一次，把控件当前文字登记为
  翻译源（Qt 动态属性），切换语言时统一重新应用。只登记文字静态的控件类型
  （QAction / QToolButton / QPushButton / QCheckBox / QGroupBox / QDockWidget / 页签 / 窗口标题），
  自由 `QLabel` 默认不登记，避免把状态栏等动态文字在切换语言时重置回初始文案。
* 语言菜单自身被标记为不参与翻译（`i18nSkip`），否则「日本語 · Japanese」这类语言名会被当成待翻译文案。
* 切换语言只改界面文字，不触碰任何计算结果、系数或导出内容。

## 5. 验证

CI 等价环境（Linux、有 gcc、`pip install -e ".[dev,web,gui]"`、
`QT_QPA_PLATFORM=offscreen`、`MPLBACKEND=Agg`）：

```text
389 passed, 2 xfailed
```

i18n 回归（9 项）中最关键的一项会把四个工作区**实际绑定的全部界面字符串**抓出来，
要求每种语言都有对应译文——今后新增工具栏项或页签而忘记配译文，会直接测试失败。
另外覆盖：帮助章节回退提示、语言菜单勾选状态、语言名的不可翻译性、
字体栈（日/韩不得以中文字体打头）、语言设置的持久化、切换后能正确切回中文。

## 6. 已知限制

1. 日文、韩文的长技术正文（实现说明、模型边界等）仍在按章节补齐；未补齐的章节显示原文
   并明确提示，不会伪装成已翻译。
2. 译文为工程用语的初稿，尚未经过母语者校对；发现措辞问题欢迎直接发邮件指出。
3. 仍只翻译**界面与帮助**。README 与 `DC/*.md` 文档、以及运行日志、报告与 CLI 提示
   目前以中文为主，属后续阶段。
4. V9.2.1 与 V9.2.0 的已知限制（模型边界、FRA 假设、Step 授权链等）保持不变，
   见各工作区帮助的「模型边界与已知限制」。
