# Smart Control：证据状态与多工况共同候选

## 状态含义

- `FEASIBLE`：当前分析频段内配置的可观测约束满足；不是全局稳定性、开关瞬态或硬件验证结论。
- `CONDITIONAL`：已观测数值检查未发现违反约束，但 `|L(Fsw)|` 不在可分析频段内，或正增益裕量门槛缺少相位交越证据。未知项仍明确显示 `UNKNOWN`，不计入共同可行区域。
- `UNKNOWN`：例如没有观测到增益交越，无法建立所需 Fc/PM 证据；不能应用。
- 其他失败状态：已观测到 PM/GM、Ms、目标匹配或开关频率增益违反约束；不能通过“允许条件采用”绕过。

默认禁止条件采用。工程师可主动选中 `Allow conditional PI (unverified Fsw / GM)`，查看缺失证据，再点击 `Apply conditional PI`。此操作只将候选交给现有分析和导出流程，既不驱动真实硬件，也不把状态升级为通过。

数字控制器频响在主奈奎斯特频段内评估。LLC/TTPL 的正常分析通常不覆盖 Fsw，不能将周期性的 H(z) 在 Fsw 的重复值冒充连续模拟链路的开关频率衰减。共同求解器拒绝奈奎斯特及以上频率网格；TTPL 各环使用自身采样率对应的有效子网格。没有外推、补造极点或新增虚构模型。模拟滤波的高频衰减、采样混叠、开关瞬态须分别验证。

稳健性报告中的 `pole_stable` 现在是 `true / false / null`。只有真实提供的离散极点稳定性证据才产生布尔值；缺少证据为 `null` 和 `POLE_STABILITY_UNKNOWN`，不能把 FRD 数据的缺失极点当作通过。

## 使用真实工作点

1. 在 LLC 或 TTPL 的现有完整模型中完成一个工作点分析。
2. 在 `Fc × PM Solution Map` 中点击 `Retain current`，保存本次已完成分析的只读快照。
3. 修改工作点并重新运行原有分析。LLC 支持母线电压、负载、PCMD 等运行点变化；TTPL 支持输入/母线电压、功率、工频相位变化。
4. 勾选要共同检查的兼容快照，生成候选或 Fc×PM 图。
5. 当前工作点作为名义点，只合成一次 PI；完全相同的 Kp、Ti、Ts/H(z) 在全部选中快照上评估，绝不为每个点重新调参。

Fc/PM 目标匹配用于名义点；其他工作点允许实际 Fc 改变，但 PM 必须不低于目标减去明确设置的容差。GM、Ms、Mt（内核可配置）、Fsw 门槛仍统一。界面显示每点状态、最差指标、来源和同一候选的多条频响。

快照只在当前会话保留，不保存进工程文件，也不自动生成输入/负载/温度/容差的完整角点集合。没有采集的工况没有验证结论。

## 一致性与失效处理

- 植物参数、传感链、采样/时序变化会清除不再兼容的快照。
- TTPL 外环包含已闭合的内环；内环控制器变化时旧外环快照失效。
- 输入、约束、选中角点或来源变化会立即作废旧候选和图。
- 已运行但晚到的旧分析结果不能恢复过期候选。
- Apply 继续使用原有完整分析作为唯一控制器所有者，保留全精度系数；既有导出使用当前已应用控制器。LLC 主窗口 JSON 保存/加载仍是设计参数项目，不会保存完整控制器或角点会话；加载新项目必须使旧候选失效。

## API

`FixedLoopCorner` 描述一个真实固定回路频响，包含唯一工作点 ID、频率数组、固定回路复数响应、采样率、开关频率和来源。

`evaluate_common_solution_point` 与 `build_common_fc_pm_solution_map` 分别返回共同候选和共同地图。所有工作点必须使用同一控制器采样率；每个工作点可保留独立频率网格。返回的 `corner_ids` / `corner_results` 保留逐点证据。调用方负责保证模型的物理兼容性；GUI 通过精确模型签名完成此检查。

参见 [SciPy 数字滤波器频响定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.freqz.html)。

当前 LLC GUI 适配器针对其标准自动损耗阻尼分析流程。额外通过 Python API 设置 `series_resistance_ohm` 的自定义阻尼来源没有被现有 `SmallSignalAnalysis` 单独记录，不能仅凭 GUI 自动签名区分该来源；此类脚本必须自行建立物理兼容性签名/独立角点集合，不应复用 GUI 自动分组。完整阻尼来源追踪属于后续工作。
