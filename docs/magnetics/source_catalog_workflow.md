## 现有桌面入口

PFC → TTPL 或 Vienna → 电感设计 → Model path → CSC PDF 来源磁环 / 参考模型。

1. 搜索并选择具体来源记录。明确型号、可用性行和纯几何分别筛选。
2. 输入匝数/叠加数，计算零偏磁 L0=N²·AL。AL 的原文测量条件（10 kHz、10 G 峰值、温度未知）随结果和工程保存。
3. 可选填写 H[Oe]，在出版图线覆盖区内计算偏置参考值。可选填写原式 B[kG] 与 f[kHz]，进行原式损耗算术；不会擅自认定这个 B 是 AC 峰值或峰峰值。
4. “主目录材料 / 原式 / 冲突”与“其他 PDF 资料 / 案例”可检索材料、公式、图线、性能点及来源问题。
5. “保存磁件工程 / 打开磁件工程 / 磁件报告”保存所选来源快照、用户声明、输入并重新计算结果。这是磁件工程，不意味着旧控制环路会话已经包含磁件数据。

LLC 磁芯/骨架数据库同样可检索来源数据，但粉芯或几何参考不会被自动转换为完整的 LLC 磁芯-骨架预设。

## 计算资格与用户声明

资料未明确给出损耗 B 的峰值约定、波形和温度适用条件。图轴覆盖区不是厂家适用域保证。因此完整 PFC 参考估算默认关闭。

用户确有依据时，可录入独立的用户模型声明，包括 B 约定、正弦参考式用于 PFC 的近似解释、H/B/f/温度范围、本次磁芯温度、涂层后边界尺寸用于几何估算以及声明依据。所有字段默认 UNKNOWN；程序不代填。声明随工程/报告保存，并始终标为用户声明的工程参考，不能冒充厂家保证或温升验证。

- 使用原文有理幂偏置与双项损耗表达式，不强拟合成旧四次多项式或单项 Steinmetz。
- 明确的源数据/模型身份冲突不可通过用户声明覆盖；AL 或材料身份冲突也会阻止依赖它的零偏磁计算。
- 来源模型拒绝越界候选、非有限数、错误计数、效率大于 1、无 Boost 电压余量的工况。
- 铜绕组估算的输入范围保持与现有编辑器一致：20–180 °C；不能把低温线性外推产生的负电阻当作损耗结果。
- 应用 L/DCR 前检查目标功率级的范围，避免控件静默钳位。恢复项目也会在改动界面前检查字段能否无损表示。
- 保存的磁件工况若与当前功率级不一致，必须先同步并重新计算，才能应用。

## 案例复算的边界

APP-023 可忠实复现文档算术：Lmin≈197.955172 µH、Bac≈0.049252382 T、磁芯损耗≈1.919893 W、线损≈1.544192 W、合计≈3.464085 W。

这些不是实测。案例混用厂商资料，120 kHz 高于嵌图最高 100 kHz 曲线；Lmin 比 200 µH 目标低约 1.0224%。原文 ΔI=(Vo−Vinpeak)²/(L·fs·Vo) 与标准 Boost 伏秒表达式不同，B 也使用固定 μ=60 近似。因此案例复算不能作为真实 PFC 求解器的物理正确性基准，更不会改变实际求解器公式来匹配纸面算例。
